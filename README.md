# Battle - Jeu JavaFX 🎮

[Java 17+](https://www.java.com/) | [JavaFX 17+](https://openjfx.io/) | [SceneBuilder](https://gluonhq.com/products/scene-builder/)

> 🎓 **Projet scolaire** réalisé en 1ère année de BTS SIO.

Battle est un jeu de combat développé en JavaFX dans lequel les joueurs s'affrontent avec différents personnages. Les interfaces ont été conçues avec SceneBuilder, et les différents écrans sont gérés au sein d'un seul fichier FXML et d'un seul contrôleur.

## Stack

- Java 17+
- JavaFX 17+
- SceneBuilder
- FXML / CSS

## Écrans du jeu

- Sélection des personnages
- Combat en cours
- Résultat du combat

## Fonctionnalités

- Choix des personnages et des adversaires
- Gestion des points de vie et des attaques
- Affichage dynamique des combats
- Code extensible pour ajouter de nouveaux personnages ou de nouvelles attaques

## Installation

1. Cloner le projet
2. Ouvrir le projet dans IntelliJ IDEA ou Eclipse
3. (Optionnel) Ouvrir les fichiers FXML avec SceneBuilder pour modifier l'interface
4. Lancer l'application via `Main.java`
